# Worldview Editor

DOM-free Valve 220 document, convex-brush, command, and WebGPU source-rendering primitives for the
Worldview browser editor. Product scope and architecture are tracked in the repository's canonical
[`docs/plan.md`](../../docs/plan.md).

This package does not contain game data. Local WAD, BSP, and map fixtures derived from commercial or
shareware games must remain outside the repository.
